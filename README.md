# QuietTranslate

原生 macOS 轻量翻译工具：划词翻译、输入翻译、本地模型，尽量减少对当前工作的打断。

实施入口：[会话交接与开发计划](docs/HANDOFF.md)。开发前阅读 [AGENTS.md](AGENTS.md)。

## 构建与使用

- 首次本机构建：执行 `zsh scripts/setup-signing.sh`，在当前用户钥匙串创建一次专用签名证书及私钥。后续必须保留并复用，不要删除或重新生成；换构建机器时应导入原身份。
- 打包：`scripts/package.sh` → `build/QuietTranslate.dmg`，同时保留 `build/QuietTranslate.app`。生成的应用适用于构建机器的 CPU 架构，要求 macOS 14 或更高版本。
- 安装：打开 DMG，将 QuietTranslate 拖入 Applications，弹出磁盘映像，再从“应用程序”启动。替换旧版前先从菜单栏退出应用。
- 应用常驻菜单栏，不在 Dock 栏显示；通过菜单栏打开翻译、设置或退出。
- 安装包默认采用稳定的本机自签名证书，未经过 Apple 公证。其他 Mac 可能需要在系统设置“隐私与安全性”中允许打开。
- 首次运行：自动打开设置，不预置任何翻译服务、模型或密钥。点击“添加引擎”，填写名称、服务地址、模型和所需的 API Key，可先“检查连接”，再“保存设置”。第一个引擎自动成为首选；未完成配置时，翻译入口会引导回设置。
- 快捷键：⌥D 划词翻译（需授权“辅助功能”），⌥T 输入翻译（Return 翻译，Shift+Return 换行，Esc 关闭）。
- 划词取词：优先读取辅助功能选区；失败时尝试当前应用菜单栏中可用的“复制”动作，不发送模拟按键。复制成功后恢复原剪贴板的各项数据格式；等待期间切换应用、按键或点击则取消取词，保留当时的剪贴板内容。取词期间再次按 ⌥D 可取消。
- 引擎管理：添加、编辑或删除 OpenAI 兼容翻译引擎，选择一个首选引擎，其他引擎可勾选“在翻译窗口中提供此引擎”。首选引擎自动翻译；通过译文上方的引擎切换条查看其他引擎，首次选中时翻译。同一次翻译中切回引擎会保留已有结果和请求状态，不重复请求。阅读区一次显示一个引擎，停止、重试和复制均作用于当前引擎。修改原文或方向后重新翻译会清除旧结果。保存后下次翻译或重新打开弹窗生效。
- 凭据：API Key 保存在钥匙串，留空保留原密钥，点击“清除已存密钥”后保存可移除，保存前可“撤销清除”。已有已保存配置继续沿用；旧版仅迁移明确保存且完整有效的引擎地址和模型；旧本地密钥在保存时迁入钥匙串。网关可能将文本转发到上游模型；使用本机 SSH 隧道时需保持隧道连接。
- 钉住窗口：点击右上角图钉，点击窗口外仍保持显示；再次点击取消钉住。关闭按钮始终有效。
- 发音：点击原文或译文旁的扬声器按钮朗读，再次点击停止；译文完成后可播放。原文自动识别语言，译文按翻译方向使用中文或英文语音。同一时间只朗读一段，修改原文、切换引擎、重新翻译或关闭窗口会停止。使用 macOS 系统语音，无需 TTS 密钥；缺少语音时按提示前往系统辅助功能下载。音色与效果取决于已安装的系统语音。
- 从旧 ad-hoc 版本首次升级后，需要在“系统设置 → 隐私与安全性 → 辅助功能”移除旧 QuietTranslate 条目，再添加 `/Applications/QuietTranslate.app` 并授权一次。后续使用同一签名身份更新可保持应用身份；不要从 DMG 或构建目录运行不同副本。旧钥匙串密钥也可能首次提示确认访问，不要删除密钥。
- 对外发行应使用 `CODE_SIGN_IDENTITY="Developer ID Application: …" scripts/package.sh` 并完成 Apple 公证。打包不会退回 ad-hoc；签名身份变更仍可能需要重新授权。

## 已知限制

不提供辅助功能选区且没有可用“复制”菜单的应用，仍需使用输入翻译。复制兜底会短暂写入系统剪贴板，剪贴板管理工具可能记录这次复制；若目标应用写入过慢或取词期间另有复制操作，可能取词失败或影响剪贴板内容。微信兼容性需在实际使用的版本中验证。运行与交互验收见 docs/HANDOFF.md 第 7 节。
