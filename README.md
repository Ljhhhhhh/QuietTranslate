# QuietTranslate

原生 macOS 轻量翻译工具：划词翻译、输入翻译、本地模型，尽量减少对当前工作的打断。

实施入口：[会话交接与开发计划](docs/HANDOFF.md)。开发前阅读 [AGENTS.md](AGENTS.md)。

## 构建与使用

- 打包：`scripts/package.sh` → `build/QuietTranslate.app`，拖入“应用程序”即可。
- 首次运行：菜单栏图标 →“设置…”确认服务地址（默认 `http://127.0.0.1:8765/v1`，模型 `hy-mt2-1.8b-q4`），点“保存并检查连接”。
- 快捷键：⌃⌥D 划词翻译（需授权“辅助功能”），⌃⌥A 输入翻译（⌘↩ 提交，Esc 关闭）。
- 每次重新打包后签名变化，可能需要在“辅助功能”中重新授权。

## 已知限制

不支持辅助功能选区接口的应用（部分 Electron/浏览器页面）取词会失败，改用输入翻译。运行与交互验收见 docs/HANDOFF.md 第 7 节，尚未执行。
